ROLE SUMMARY
Seeking an SAP Integration Consultant with experience in SAP CPI / Integration Suite and SAP PI/PO to design, develop, deploy, monitor, and support enterprise integrations between SAP and non-SAP systems. - Build and maintain SAP CPI iFlows using content modifiers, routers, request-reply, message transformations, process steps, and exception subprocesses.

- Develop message mappings, XSLT mappings, value mappings, and user-defined functions where applicable.
- Work with REST APIs, API consumption and publishing, Swagger documentation, and deployment through CLI.
- Configure security materials, certificates, connectivity tests, and SAP Cloud Connector for on-premises connectivity.
- Monitor message processing, deployed artifacts, trace logs, component status, and runtime errors; troubleshoot failed interfaces.
- Perform unit, integration, and performance testing using tools such as Postman and SOAP UI.
- Support production incidents, enhancements, transports, and coordination with functional and technical teams.
